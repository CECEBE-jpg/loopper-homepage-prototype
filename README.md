# Loopper home page redesign

Static HTML and CSS build of the Figma frame "Home page vFeedback"
(file `7mafJc1Sah8b22Jr6qjZ7U`, node `168:5171`).

Open `index.html` in a browser. There is no build step.

- `index.html`: page markup
- `styles.css`: page frame styles, followed by styles generated from Figma
- `assets/`: images and icons exported from Figma

The layout is the fixed 1491px desktop frame. A small script scales it down on narrower screens; there is no dedicated mobile layout yet.
